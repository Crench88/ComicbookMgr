Site backup

Download a zip of the live database, cover files, and digital archives. Temporary zips are stored separately from production files.

What is included

  • comicbook.db — a snapshot of the SQLite database (BLOBs still in the DB stay in this file)
  • covers/ — filesystem covers and WebP thumbnails
  • digital/ — uploaded CBZ/CBR files, if any

Not included: .env, reader_cache, API cache, or these temporary backup zips. Creating a backup does not move or delete the live database or cover folders.

Temporary zips on the server

These files live in instance/backups/ only. Deleting them never removes instance/comicbook.db, instance/covers/, or instance/digital/.
